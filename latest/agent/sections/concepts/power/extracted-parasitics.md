## Extracted parasitics

A `pnr` source reads the P&R run's extracted `<top>.routed.spef` when the PDK sets [`rcx-rules`](https://rtl-buddy.github.io/rtl_buddy/v8/concepts/pnr/#configure-the-physical-platform). Otherwise it estimates parasitics from global routing with the wire RC the P&R run timed and repaired with, sourcing the PDK's [`layer-rc-tcl`](https://rtl-buddy.github.io/rtl_buddy/v8/concepts/pnr/#set-wire-rc) first when set. A configured `layer-rc-tcl` or `platform-tcl` missing from disk fails the run at `setup`.

When the P&R run has [`session` hooks](https://rtl-buddy.github.io/rtl_buddy/v8/concepts/pnr/#run-tcl-hooks), the power session runs them as each P&R session does, on both paths, after the layer RC and before the SPEF or the estimate: the database keeps neither a hook's `set_wire_rc` nor analysis settings such as `set_case_analysis` or `set_load`. The flow variables a hook can read are set as in P&R (`$DESIGN`, `$SIGNAL_LAYERS`, `$LIBERTY` and the rest), except `$OUT_DIR`, which names the power run's directory so that a power run writes nothing into the P&R run. The hooks run in the P&R run's directory, so their relative paths resolve as in P&R. The platform's `dont-use-cells` and `keep-sizing-vt` are applied before them, as in P&R. Two things differ: a multi-corner P&R run that gives each corner its own SDC mode has one mode here, read from the routed SDC, and `$NETLIST` names the synthesis netlist, not the copy a P&R run with `blocks:` reads. A missing hook fails the run at `setup`.

The contents of `layer-rc-tcl` when the run estimates, the `session` hooks and the P&R run's `inputs:` are part of the run's configuration digest, so editing one makes a new experiment.

The SPEF is used only if its `pnr.tcl` contains `write_spef` and the SPEF is no older than that `pnr.tcl`. Otherwise the run logs a `power.spef_rejected` warning naming the reason and uses the estimate. The `parasitics` result field (`spef` or `estimated`) and the summary's Parasitics column show which was used, and one ODB measured both ways counts as two experiments.

Extraction and the estimate can differ in either direction: switching power and slack move with the wire capacitance each one gives.

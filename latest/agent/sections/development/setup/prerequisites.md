## Prerequisites

- Python 3.11 or later.
- [`uv`](https://docs.astral.sh/uv/).
- `git`.

`uv` manages the environment from `pyproject.toml` and `uv.lock`. External EDA tools are required only for their matching commands; see [Installation](https://rtl-buddy.github.io/rtl_buddy/v6/install/#external-tools-by-feature).

## Set Review Scope

Review changes introduced by the pull request and the behavior they affect. If the pull request edits a guideline, use the base-branch version of that guideline to review the edit.

Apply [Engineering Guidelines](https://rtl-buddy.github.io/rtl_buddy/v6/development/guidelines/) to every change. Report a violation only when changed code conflicts with a rule or contract you can cite; preferences are not defects.

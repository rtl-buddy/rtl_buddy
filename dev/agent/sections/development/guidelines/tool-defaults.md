## Tool Defaults

Give each underlying tool's commands the behaviour their users expect: the tool's own default, or the setting its reference flows commonly use (for OpenROAD, OpenROAD-flow-scripts). A knob that departs from both is unset or off by default, so a project chooses it. A default that departs from both works around a named tool bug, has its section in [Quirks & Known Issues](https://rtl-buddy.github.io/rtl_buddy/dev/known-issues/), and has an issue that tracks dropping it once the supported tool versions fix the bug.

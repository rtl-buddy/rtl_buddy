## Flow steps

The generated `pnr.tcl` runs these steps in order:

1. Source `platform-tcl` when set, read Liberty, LEF, the synthesis netlist and the SDC, set the design's max fanout when `max-fanout` is set, then source `layer-rc-tcl` when set.
2. Initialize the floorplan, create routing tracks and run `insert_tiecells` for the PDK's `tie-hi` and `tie-lo` ports, one tie cell per constant net.
3. Place macros, insert tap and endcap cells when `tapcell-tcl` is set, build the power grid and place the IO pins, checking [`pins-complete`](https://rtl-buddy.github.io/rtl_buddy/dev/concepts/pnr/#check-that-every-port-is-placed) when set, then run `buffer_ports -inputs -outputs` when the run buffers its ports (`buffer-ports`, on by default for `harden: true`; see [Harden a block](https://rtl-buddy.github.io/rtl_buddy/dev/concepts/pnr/#harden-a-block)).
4. Create the [`lifetime: global-placement`](https://rtl-buddy.github.io/rtl_buddy/dev/concepts/pnr/#floorplan-controls) blockages and the [rotated-macro](https://rtl-buddy.github.io/rtl_buddy/dev/concepts/pnr/#rotate-a-macro) blockages, run global placement, with `-reference_hpwl` when `placement.reference-hpwl` is set and `-routability_driven` / `-routability_use_grt` when `placement.routability-driven` / `placement.routability-use-grt` are `true`, and remove those blockages again. Then run `repair_tie_fanout` for each tie port, which gives every constant-driven load its own tie cell `placement.tie-separation` microns away (default 0).
5. Run `repair_design`, legalization, clock-tree synthesis (with `-apply_ndr` when `cts-apply-ndr` is set), setup repair when `post-cts-setup-repair` is set, hold repair and a final legalization. A [probe](https://rtl-buddy.github.io/rtl_buddy/dev/concepts/pnr/#probe-without-timing-repair) skips the setup and hold repair.
6. Route globally with `-verbose` and a congestion report, after `set_global_routing_layer_adjustment` when `routing-layer-adjustment` is set, run the [global-route repair](https://rtl-buddy.github.io/rtl_buddy/dev/concepts/pnr/#repair-on-the-global-route) when `global-route-repair` or `global-route-hold-repair` is set, route in detail at the run's `detailed-route-verbose` level, run the [post-route repair](https://rtl-buddy.github.io/rtl_buddy/dev/concepts/pnr/#repair-on-the-detailed-route) rounds when `post-route-repair` is set, insert fill, extract parasitics when `rcx-rules` is set, then write reports and outputs. A probe stops after global route.
7. After OpenROAD exits, compare the routed DEF with every macro the floorplan located and every pin it placed exactly; see [Check the routed floorplan](https://rtl-buddy.github.io/rtl_buddy/dev/concepts/pnr/#check-the-routed-floorplan).

A tie port the PDK leaves unset gets neither tie step.

The run's [`hooks:`](https://rtl-buddy.github.io/rtl_buddy/dev/concepts/pnr/#run-tcl-hooks) are sourced between these steps, each at the boundary its name gives; `macro-placement` replaces the macro placement of step 3.

## Install OpenROAD

OpenROAD 25Q1 or newer must be on `PATH` or configured under `cfg-power-tools`. Power runs currently support only `tool: openroad`; unsupported tools report `SKIP`.

The selected `cfg-pnr-platforms` entry supplies the PDK and Liberty corner. See [Place-and-Route](https://rtl-buddy.github.io/rtl_buddy/dev/concepts/pnr/#configure-the-physical-platform).
